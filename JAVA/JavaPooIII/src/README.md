# Employee Generation

## **Requerimientos**
1. Trabajar bajo el paradigma de POO.
2. Oranziar el proyecto en package. 
3. Crear métodos para Manager, Developer, que permitan crear, recuperar, buscar, eliminiar en DB.

## **Organización del Packege.**
- *model*: `Employee.java`, `Manager.java`, `Developer.java`
- *service*: `EmpoyeeService.java`, `ManagerService.java`, `DeveloperService.java`
- *exeptions*: `EmployeeNotFoundExeption.java`
- *main*: `Main.java`
