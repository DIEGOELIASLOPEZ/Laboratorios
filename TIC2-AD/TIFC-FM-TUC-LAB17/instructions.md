
# Instrucciones

> Instala y ejecuta Bootstrap con alertas que muestren y oculten mensajes en tiempo real, cuadrícula, formulario y barra de navegación.

## Tarea 1: Instalar Bootstrap con un enlace CDN
1. Ve a bootstrap.com [Bootstrap](https://getbootstrap.com/)✅
2. Desplázate hacia abajo y copia los enlaces de "Incluir vía CDN".✅
3. Instala esos enlaces.✅

- Inserta la etiqueta `link` en la etiqueta `header`.✅

- Inserta la etiqueta `script` debajo de la etiqueta `body`.✅

## Tarea 2: Agregar alertas dinámicas a tu sitio web
1. Agrega un botón que se usará para mostrar una alerta; llámalo "El Botón". ✅
2. El Botón debe mostrar una alerta al hacer clic en él. ✅
- Al hacer clic en el botón, debería aparecer el mensaje "Alerta, alguien pulsó el botón".✅

- Al hacer clic en la "x", debería ser posible descartar la alerta. ✅

- Consejo: No olvides añadir las dependencias necesarias para que la función de alerta funcione con Bootstrap. ✅

## Tarea 3: Usa la cuadrícula de Bootstrap para crear un diseño web básico.
1. Añade un contenedor.
2. Adapta el contenedor a flexbox con Bootstrap.
3. Crea dos filas.
4. La primera fila debe dividirse en tres secciones.

- La primera sección debe contener el texto "lado izquierdo".

- La segunda sección debe contener el texto "lado central".

- La última sección debe contener el texto "lado derecho".
5. La sección central de la primera fila debe ocupar 8 de las 12 columnas disponibles.

- Las columnas restantes deben ocupar 2.

- Asegúrate de que el número total de columnas no supere las 12. 6. La última fila debe contener el texto "Pie de página".

## Tarea 4: Agregar un formulario básico
1. Agregue un formulario a su sitio web usando Bootstrap.

2. El formulario debe tener campos de correo electrónico y área de texto.
3. Un botón para enviar.

## Tarea 5: Agregar una barra de navegación
1. Agregue una barra de navegación en la parte superior de su sitio web.
2. Asegúrese de que la barra de navegación tenga dos listas llamadas "Inicio" e "Index2".
3. Cree un enlace a "Index2" en su página web principal (index.html).
4. Asegúrese de que la página web secundaria (index2.html) tenga un enlace a "Inicio".
